# Web3Hot

A Web3 news aggregation website with curated feeds, event grouping, topic pages, periodic reports and a BTC market dashboard.

See the [Chinese README](README.md) and [deployment guide](docs/deploy.md) for setup and current limitations.

This repository is a source snapshot of Web3Hot. It retains the public branding and source configuration, but contains no production data, credentials or logs. Agent access, MCP, RSS and the public API are temporarily disabled at the web entry point; internal APIs remain available for server-side rendering.
