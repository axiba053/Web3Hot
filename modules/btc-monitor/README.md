# BTC 状态监控

公开页面优先展示北京时间当天行情、风险观察和近期事件，中期趋势及链上指标作为背景。管理员查看持续确认的异常证据、通用合约风险建议和邮件回执；现有告警仍面向数天至数周。
不读取交易账户，不执行交易，不调用模型，不计算个人开仓数量或杠杆倍数。

Binance 的报价、分时、日线与盘口使用官方公开行情接口 `data-api.binance.vision`，不需要 API Key。服务器访问交易 API 域名 `api.binance.com` 可能返回地区限制 HTTP 451；部署验收需检查实际数据时间及来源错误，不能仅检查定时任务是否完成。

## 数据与边界

19 个来源入口提供 33 项数值指标及 3 类官方日程。Binance 提供现货报价、15 分钟分时、完整 UTC 日线、现货主动买卖差额和可见盘口；
OKX 提供币本位永续 OI、历史结算费率和永续溢价；DefiLlama 提供美元稳定币供给；FRED 提供 DGS2、DFII10、DTWEXBGS；
Coinbase/Kraken 提供 USDT/USDC 美元报价；Alternative.me 提供日频恐惧与贪婪指数；Bitview 提供链上指标，美联储/BLS 提供日程。Farside ETF 页面仅接受完整已披露行，访问验证或部分披露视为缺失。
DTWEXBGS 不是 ICE DXY；永续溢价不是季度年化基差；500 档内深度只是可见深度下界；现货 CVD 不是净资金流入。

每个观测保存指标、数值、源标识、数据时间、首次采入时间。重复数据不改写首次采入记录。
来源每天重取历史不代表历史数据在过去已可获得。历史回测必须另外处理公布延迟与版本，不可直接使用这些回填数据。
读取保留最近 8 天原始观测以准确比较 7 日变化，更早数据按 UTC 日抽样，展示约 180 天；底层原始观测保留 190 天。
宏观和 ETF 按日披露，节假日允许更长滞后，具体期限在 catalog.ts 中展示；缺失与过期均不作零处理。

## 状态和告警

- 趋势继续恶化：7 日收益和相对 20 日均价均为负，且较前一完整日进一步下降；7 日买卖差额占比低于中性带下沿且进一步下降，稳定币供给也收缩。趋势偏弱本身不等于继续恶化。
- 趋势继续改善：价格指标为正且较前一完整日上升，买卖占比高于中性带上沿且继续上升，稳定币供给扩张，宏观未同步收紧，费率不处于高分位。
- 买卖占比 = 7 日主动买卖差额 / 同期成交额 × 100%；中性带为此前 90 个自然日内日样本绝对值的中位数，至少 60 天，排除当前日及未来数据。中位数为零或历史不足时暂停相关组合判断，不退回正负号判断。
- 后台分别显示数据不足、条件不满足、待确认观察、已有确认告警；候选只展示证据与确认进度，仓位建议仅在已确认告警记录中展示。
- 宏观压力：广义美元上升，2 年利率或 10 年实际利率上升，同时 BTC 趋势偏弱。
- 杠杆拥挤：费率处于日样本 90/10 分位之外且符号对应，币本位 OI 增加，并有同方向价格趋势。
- 盘口风险：可见深度低于历史 10 分位，同时价差高于 90 分位。
- 稳定币风险：美元报价持续偏离 1% 以上。只是单场所异常，邮件提醒核查其他市场与发行商。

分位需要至少 60 个日样本；新采集 OI 需要积累至少 7 天。普通条件至少持续 6 小时、3 次不同证据观测；
稳定币异常至少持续 15 分钟、2 次不同观测。相同报价时间不增加确认次数，因此日频组合可能需要数日确认。
中断超过 45 分钟或必要数据失效会重置候选确认，不将原有告警自动解除。解除也需 6 小时、3 次观测确认。
同一风险持续时不重复告警；确认恢复后重新出现才创建新告警。不同风险单独记录，单轮邮件合并。

这些是保守的可解释观察规则，尚未证明预测收益或最佳阈值。公开状态是当前观测，不等于已通过持续确认的告警。
重大新闻继续由原资讯源呈现，不自动把标题当作已确认突发事件；宏观日历链接官方公布入口。

## 邮件与运维

环境变量见根目录 .env.example。只在 worker 中采集、评估和发送邮件，页面只读已存数据。
配置与邮件启用状态可在后台检查，SMTP 凭据不返回 API、不进入页面、不写入告警。
数据库锁避免多 worker 重复采集，原子领取防止重复发送；SMTP 不明确失败不盲目重试，交给管理员核查。
来源问题在信号源健康栏展示，避免混同市场风险。

验证：`npm run typecheck`；`DATABASE_URL=postgres://.../btc_test npm test`；
`npm run build -w @aihot/web && node --test apps/web/tests/*.test.ts`；运行后 `node scripts/smoke.ts --base http://localhost:3000`。

## 链上数据与官方日历

- Bitview：免费、免密钥 API，官方 OpenAPI 的 license 字段标注 MIT（https://bitview.space/openapi.json），使用固定批量查询每 12 小时抓取最近 181 个 UTC 日，排除当日未完成数据。页面直接署名并链接原站。MVRV 采用全 UTXO 比率；STH 为 **150 天**（不是常见的 155 天）；365 天以上供应占比合计 12 个互斥区间。日数据按各序列的索引与日期对齐，缺少任一区间不输出比例，缺失不当零；数值超过 72 小时标记过期。币龄为单调区块时间口径，分母为全部未花费输出供应；不是识别到的真实投资者买卖。
- 官方日历：每 12 小时读取 FOMC 日历和 BLS CPI/Employment Situation 发布日程网页。BLS 时间按 America/New_York 换算 UTC，在页面显示北京时间；FOMC 只显示美国东部会议结束日期，不虚构声明时刻。各来源分别保留最新快照，成功抓取完整替换以处理改期/撤销；失败保留最后成功记录和更新时间，超过 48 小时显示过期。每个来源展示接下来的最多三项事件，未来为空与抓取失败分别处理。
- S&P 500/VIX 仍保留解释和原站入口：免费访问不自动解决公开再展示条件，本轮未复制这些序列。
- 链上数据和日历不参与五维状态、持续确认或邮件告警。读者访问只读已存数据，不触发外部采集。
- 新迁移 0094_btc_calendar.sql 只新增 btc_calendar_snapshots，保存各官方日程快照。无新环境变量，无付费订阅，不删除已有数据。公开日历经过 publication/btc-monitor.ts 白名单投影。

## 当天总览与按需详情


公开页面向在电脑上不定时查看当天行情的读者：顶部展示当日方向与振幅，左侧显示当天价格走势、当日涨跌/振幅/成交额，右侧集中风险观察和最近两项有效宏观事件。中期、资金情绪、美元利率和链上指标以紧凑的背景表呈现；其余指标通过“全部指标”访问。关键数值直接可见，解释、历史走势、最近观测与完整日历进入统一右侧详情面板。面板支持 Escape、遮罩和按钮关闭、焦点恢复，手机占满屏幕。

新增 Binance 15 分钟 K 线来源（每 15 分钟，最近 192 根），提供 intradayPrice/dayReturn/dayRange/dayVolume 四项数值。以共享北京时间工具定义 00:00 边界，只处理已完成 K 线；日内累计要求从零点连续，缺失后不继续计算累计，价格曲线在缺口处断开。当日指标跨北京时间零点立即失效，常规最长有效期 1 小时。价格走势额外保存当日第一根 K 线开盘价；未发生时段留空。日内振幅为高低价差除以零点开盘价，成交额不表示净流入；都不是滚动 24 小时口径。日内数据不计算历史日分位，不改变原五维状态。

OI 对照采用零点或之前最近的一条观测，距离零点不得超过 90 分钟；标明实际基准时间，对照缺失时显示当前 OI 原值。小图显示原始 OI，不将其误标为涨跌曲线。

公开风险栏只展示有效数据支持的稳定币 1% 偏离、历史深度低 10% 且价差高 10%、资金费率历史极端 10% 观察。费率极值本身不确认多空拥挤；历史基线缺失与未触线分别说明。这些是当前参考，不使用管理员建议，不改变原持续确认规则或邮件发送。下一事件只从未过期日程读取；没有时分的 FOMC 不生成小时倒计时。打开或刷新页面只读已有数据，不触发采集。


对外 Agent 接口当前暂停；网页通过私有 API 读取上述数据，部署方式见根目录 docs/deploy.md。
